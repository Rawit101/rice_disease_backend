# เทียบโมเดลและ label อัตโนมัติสำหรับรูปทั้งหมด

อ่าน report.json เพื่อดูจำนวนผลรอบนี้ รูปต้นทางอยู่ครบทุกไฟล์ใน images/pool การประมวลผลครบไม่ได้หมายความว่าทุกรูปมีขอบเขตโรคที่ถูกต้องแล้ว

## ดูผลทั้งสองโมเดล

เปิด terminal ในโฟลเดอร์นี้ แล้วรัน:

```bash
python -m http.server 8768 --bind 127.0.0.1
```

เปิด http://127.0.0.1:8768/compare.html เพื่อดูภาพเดิม / โมเดลชุดฝึก v8 / โมเดลชุดฝึก v6 / label ที่รวมแล้ว เทียบทีละรูปหรือกรองตามชื่อโรคและปัญหาได้ ลูกศรซ้ายขวาเลื่อนรูปได้ ชื่อ v8/v6 เป็นชื่อชุดการฝึกเดิม ไม่ใช่รุ่นสถาปัตยกรรม YOLO

## ไฟล์ส่งเทรน

- data.yaml ใช้ label อัตโนมัติที่มีผลทำนาย และภาพ/ขอบเขตที่ตรวจแล้ว ไม่รวมภาพที่รู้แล้วว่ามีปัญหาจากการตรวจด้วยตา
- train.txt และ val.txt เป็นรายการภาพจริง จัดรูปซ้ำที่ตรวจพบให้อยู่ฝั่งเดียวกัน validation เป็นชุดย่อยที่ AI ตรวจแล้วและครอบคลุมโรคจริงเพียง 3 คลาส จึงต้องใช้ val/test เดิมประกอบการวัดผลทั้ง 9 คลาส
- labels/pool เป็น YOLO Segmentation polygon ที่ไม่มีคะแนนต่อท้าย หมายเลข 0–8 ตรงกับ best.pt เดิม
- predictions เก็บคะแนน ผลของโมเดลแต่ละตัว ผลตรวจซ้ำความละเอียดสูง และข้อขัดแย้งแยกต่างหาก
- manifest.json และ image_status.csv ระบุที่มาและสถานะทุกรูป รวมรูปที่ยังไม่มี label
- weights/best.pt เป็นสำเนาโมเดลเดิม ไม่ได้เทรนหรือเปลี่ยนน้ำหนัก
- data_all_predictions.yaml รวมผลทำนายแม้ภาพนั้นเคยตรวจพบกรอบผิด/ตกหล่นและภาพ healthy ที่ยังไม่ผ่านการตรวจ มีไว้ตรวจ/แก้ผลอัตโนมัติ ไม่ใช่ชุดข้อมูลที่ยืนยันความถูกต้องแล้ว

## หลักการรวมผล

ใช้ผลโมเดลเดิมสองรุ่นเป็นขอบเขตตั้งต้น เก็บคลาสที่โมเดลทำนายจริง ไม่บังคับเปลี่ยนคลาสให้ตรงโฟลเดอร์ ขอบเขตทับกันจะเลือกคะแนนสูงกว่าและบันทึกผลที่ขัดกัน คะแนนของสองรุ่นไม่ได้ผ่านการปรับเทียบให้เป็นความน่าจะเป็นเดียวกัน การเลือกนี้จึงเป็นกฎอัตโนมัติที่ผิดได้

ภาพที่ทั้งคู่ตรวจไม่เจอจะตรวจซ้ำที่ 1280 px ด้วย threshold 0.10 เพื่อหาเป้าหมายที่ตกหล่น ผลนี้มีความมั่นใจต่ำกว่าและมีธงเตือน ไม่ใช่การยืนยันรอยโรคใหม่ ส่วนขอบเขตที่ AI เคยตรวจแล้วจะใช้ผลแก้ไขนั้น

ชื่อที่โมเดลทำนายไม่ตรงโฟลเดอร์ รูปเดียวกันแต่ชื่อโรคต่างกัน และผลที่ยังไม่มีผู้เชี่ยวชาญยืนยัน จะมีสถานะชัดเจน ความเห็นตรงกันของโมเดลทั้งสองไม่ได้รับรองความถูกต้อง เพราะอาจมีข้อมูลการฝึก/ข้อผิดพลาดร่วมกัน

ไฟล์ label ว่างสร้างเฉพาะภาพที่มาจากโฟลเดอร์ healthy ตามข้อมูลต้นทาง ชุด train ปกติใช้เฉพาะภาพ healthy ที่ AI เคยดูและยอมรับแล้ว ไม่ถือว่ารูปตรวจไม่เจอโรคเป็นภาพ healthy โดยอัตโนมัติ

โรคถอดฝักดาบและรากปมอยู่นอก 9 คลาสของโมเดลเดิม จึงเก็บรูปและผลเปรียบเทียบไว้ แต่ไม่ใช้คำทำนายโรคเดิมหรือหน้ากากวัตถุทั่วไปแทน annotation ของสองโรคนี้ ภาพที่ยังไม่มีขอบเขตจะไม่ถูกใส่เข้า train เป็นภาพพื้นหลัง

## ให้เพื่อนนำไปเทรนต่อ

```bash
python -m pip install -r requirements.txt
python validate_full_rice.py
python merge_rice_training.py --original-yaml /path/to/original/data.yaml
yolo segment train model=weights/best.pt data=merged_with_original/data.yaml imgsz=800 epochs=50 batch=4 device=0
```

ให้แทนพาธ data.yaml ด้วยชุดเดิมที่มีอยู่จริง ตัวช่วยรักษา val/test เดิมและกันภาพเพิ่มที่ตรวจพบว่าซ้ำหรือคล้ายภาพประเมิน ชุดเดิมไม่อยู่ในแพ็กนี้จึงยังไม่ได้รวมจริง คำสั่ง train เป็นตัวอย่างสำหรับ NVIDIA ให้ผู้เทรนปรับ batch/epochs ตามเครื่อง ไม่ใช้ resume=True เมื่อเปลี่ยนข้อมูล ไม่มีการสั่งเทรนหรือทับ best.pt ในขั้นตอนทำ label นี้

ชุดอัตโนมัติช่วยลดงาน แต่ยังผิดได้ การโหลดไฟล์ผ่านและมี label จำนวนมากไม่ได้รับรองว่าจะทำให้โมเดลแม่นขึ้น ต้องประเมินด้วยภาพอิสระที่มี annotation ถูกต้อง
